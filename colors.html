Checking contrast ratio

Blue borders around each combination indicates contrast ratio at or exceeding 7:1, which meets WCAG 2.1 AAA standards for all text, graphics and form components.

Green borders around each combination indicates contrast ratio at or exceeding 4.5:1 but lower than 7:1, which meets WCAG 2.1 AA standards for all text, graphics and form components as well as WCAG 2.1 AAA standards for larger text, graphics and form components.

Yellow borders around each combination indicates contrast ratio at or exceeding 3:1 but lower than 4.5:1, which only meets WCAG 2.1 AA standards for larger text, graphics and form components but fails WCAG 2.1 AAA standards for any text, graphics and form components.

Red borders around each combination indicates contrast ratio lower than 3:1, which fails WCAG 2.1 AA standards for any text, graphics and form components.
