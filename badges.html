Badges

Badges are used to display counts or labels next to elements.

Examples

Badges comes in different semantic variants, as well as weights (default, subtle, outlined).

Default: Progressive Destructive Error Warning Success Notice

Subtle: Progressive Destructive Error Warning Success Notice

Outlined: Progressive Destructive Error Warning Success Notice 

<!-- Default badges ->
<span class="badge badge-progressive">Progressive</span>
<span class="badge badge-destructive">Destructive</span>
<span class="badge badge-error">Error</span>
<span class="badge badge-warning">Warning</span>
<span class="badge badge-success">Success</span>
<span class="badge badge-notice">Notice</span>

<!-- Subtle badges ->
<span class="badge badge-subtle badge-progressive">Progressive</span>
<span class="badge badge-subtle badge-destructive">Destructive</span>
<span class="badge badge-subtle badge-error">Error</span>
<span class="badge badge-subtle badge-warning">Warning</span>
<span class="badge badge-subtle badge-success">Success</span>
<span class="badge badge-subtle badge-notice">Notice</span>

<!-- Outlined badges ->
<span class="badge badge-outlined badge-progressive">Progressive</span>
<span class="badge badge-outlined badge-destructive">Destructive</span>
<span class="badge badge-outlined badge-error">Error</span>
<span class="badge badge-outlined badge-warning">Warning</span>
<span class="badge badge-outlined badge-success">Success</span>
<span class="badge badge-outlined badge-notice">Notice</span>

They scale relative to font size, i.e. 87.5% of inherited font size (0.875em). For example, heading 1 have a font size of 2.25rem, so the badge will have a font size of 1.96875rem.

Buttons

Badges can be used in buttons, for example to indicate a notification count.

<button class="btn btn-primary btn-progressive">
    Notifications
    <span class="badge badge-destructive">3</span>
</button>
