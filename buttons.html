Buttons

Use buttons to allow users to take actions or make choices.

Base class

Buttons have a base class of btn that can be used to style them.

<button type="button" class="btn">Button</button>

Variants

Buttons can have different variants by adding additional classes.

Normal Primary (btn-primary) Quiet (btn-quiet)
Default
Progressive
Destructive
Disabled

Button sizes

Buttons can come in different sizes: small, medium and large, with medium being the default. Use btn-lg for large buttons, or btn-sm for small buttons.

<button type="button" class="btn btn-large">Large button</button>
<button type="button" class="btn">Medium button</button>
<button type="button" class="btn btn-small">Small button</button>
