Tooltips

Themed tooltips that replace the browser ones.

Note: This component requires JavaScript as it relies on js/tooltips.js, which is imported into the main JavaScript file, js/codexify.js.

Examples

Tooltips show on hover or focus of the element which triggers a tooltip, and when clicked, the tooltip stays shown. Clicking outside the tooltip or that element, the tooltip hides.

<button class="btn" data-c-toggle="tooltip" data-c-title="This is a tooltip">Default tooltip</button>

Using on links

Tooltips can be used on links, such as this link.

<a href="#" data-c-toggle="tooltip" data-c-title="This is a link">this link</a>

Placement

By default, tooltips are placed above the element. Tooltips can be placed above, below, at left and right of the element.

<button class="btn" data-c-toggle="tooltip" data-c-placement="left" data-c-title="Left">Left</button>
<button class="btn" data-c-toggle="tooltip" data-c-placement="top" data-c-title="Top">Top</button>
<button class="btn" data-c-toggle="tooltip" data-c-placement="bottom" data-c-title="Bottom">Bottom</button>
<button class="btn" data-c-toggle="tooltip" data-c-placement="right" data-c-title="Right">Right</button>
