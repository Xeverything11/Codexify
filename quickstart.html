Codexify is the open-source design framework, based on Wikimedia's Codex design system.

Browser support

Codexify is supported in the following browsers:

Browser Chrome / Edge / Chromium Firefox Safari
Windows Yes Yes No
macOS Yes Yes Yes
Linux Yes Yes No
Android Yes Yes No
iOS & iPadOS Yes, but WebKit Yes, but WebKit Yes
Version scope Current & previous versions in the past year Current & ESR versions officially supported by Mozilla Current & previous 3 versions
Version range 141+ 115+ 17+

For Chrome, Edge & Firefox on iOS, it uses WebKit engine like Safari due to Apple's restrictions.

Browser support is subject to change as newer alpha versions are released. It will be frozen and lowered to the minimum bound at the time of the next beta releases.

Getting started

To get started with Codexify, copy the following code into your HTML file:

<!DOCTYPE html>
<html lang="en">
    <head>
        <meta charset="UTF-8" />
        <meta name="viewport" content="width=device-width, initial-scale=1.0" />
        <title>Example</title>
        <link rel="stylesheet" href="https://xeverything11.github.io/Codexify/codexify.css">
    </head>
    <body>
        <h1>Hello, world!</h1>
    </body>
</html>

Then, open the HTML file in your browser to see the result.
