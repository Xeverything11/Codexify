Quickstart

Codexify is the open-source design framework, based on Wikimedia's Codex design system.

Browser support

Codexify is supported in the following browsers:

Browser Chrome / Edge / Chromium Firefox Safari
Windows Yes Yes No
macOS Yes Yes Yes
Linux Yes Yes No
Android Yes Yes No
iOS & iPadOS Yes, but WebKit Yes, but WebKit Yes
Version scope Current & previous versions in the past year Current & ESR versions officially supported by Mozilla Current & previous 3 versions
Version range 142+ 115+ 17.6+

For Chrome, Edge & Firefox on iOS, it uses WebKit engine like Safari due to Apple's restrictions.

Browser support is subject to change as newer alpha versions are released. It will be frozen and lowered to the minimum bound at the time of the next beta releases.

Why support Firefox 115+ when Tailwind v4 supports Firefox 128+ and Bootstrap v6 supports Firefox 132+?

Because Mozilla is still providing Firefox 115 ESR, the last version of Firefox for Windows 7, 8 and 8.1, and macOS 10.12 Sierra, 10.13 High Sierra and 10.14 Mojave, with security updates until March 2027, so Codexify supports Firefox 115+ until then. According to StatCounter, Firefox 115 ESR has 0.12% market share as of October 2026. This might seem tiny, but considering all versions of Firefox have a total of 2.56% market share, this accounts for over 4% of all Firefox versions.

Getting started

To get started with Codexify, copy the following code into your HTML file:

<!DOCTYPE html>
<html lang="en">
    <head>
        <meta charset="UTF-8" />
        <meta name="viewport" content="width=device-width, initial-scale=1.0" />
        <title>Example</title>
        <link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/Xeverything11/Codexify@0.7.0/codexify.css">
    </head>
    <body>
        <h1>Hello, world!</h1>
    </body>
    <script type="module" href="https://cdn.jsdelivr.net/gh/Xeverything11/Codexify@0.7.0/js/codexify.js"></script>
</html>

Then, open the HTML file in your browser to see the result.
