Quickstart

Codexify is the open-source design framework, based on Wikimedia's Codex design system.

Browser support

Codexify is supported in the following browsers:

  • Google Chrome and Chromium-derived browsers (current and previous versions released in the past year)
  • Mozilla Firefox (current stable and all supported ESR versions)
  • Microsoft Edge (current and previous versions released in the past year)
  • Apple Safari (current and previous 3 versions)

That means Chrome 141+, Firefox 115+, Edge 141+, Safari 17+, and Chromium-derived browsers such as Opera and Samsung Internet. Internet Explorer is not supported.

Browser support is subject to change as newer alpha versions are released. It will be frozen at the time of the next beta release.

Getting started

To get started with Codexify, copy the following code into your HTML file:

<!DOCTYPE html>
<html lang="en">
    <head>
        <meta charset="UTF-8" />
        <meta name="viewport" content="width=device-width, initial-scale=1.0" />
        <title>Example</title>
        <link rel="stylesheet" href="https://xeverything11.github.io/Codexify/codexify.css">
    </head>
    <body>
        <h1>Hello, world!</h1>
    </body>
</html>

Then, open the HTML file in your browser to see the result.
