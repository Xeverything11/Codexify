Alert

An alert is a message that communicates important information to the user.

Example

Alerts don't have a default class, only the base and modifier classes. You need to add a modifier class to style the alert.

Something went wrong! Please try again later.
Something might be wrong! Please check your input.
Operation completed successfully!
To login, you need to enter password with at least 8 characters, including a number and a special character. 
<div class="alert alert-error" role="alert">
    Something went wrong! Please try again later.
</div>
<div class="alert alert-warning" role="alert">
    Something might be wrong! Please check your input.
</div>
<div class="alert alert-success" role="alert">
    Operation completed successfully!
</div>
<div class="alert alert-notice" role="alert">
    To login, you need to enter password with at least 8 characters, including a number and a special character.
</div>
Accessibility note: Using color to add meaning only changes the visual indication and therefore is not accessible to screen readers. Use text or icons to convey meaning in addition to color.

You can add links to alerts by using the .alert-tag in <a> tags inside the alert. For example:

Something went wrong! Please try again later.
Something might be wrong! Please check your input.
Operation completed successfully! View details.
To sign up, you need to accept terms and conditions. 
<div class="alert alert-error" role="alert">
    Something went wrong! Please <a href="#" class="alert-tag">try again later</a>.
</div>
<div class="alert alert-warning" role="alert">
    Something might be wrong! Please <a href="#" class="alert-tag">check your input</a>.
</div>
<div class="alert alert-success" role="alert">
    Operation completed successfully! <a href="#" class="alert-tag">View details</a>.
</div>
<div class="alert alert-notice" role="alert">
    To sign up, you need to accept <a href="#" class="alert-tag">terms and conditions</a>.
</div>
