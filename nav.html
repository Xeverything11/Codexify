Nav

Component used to navigate through pages.

Examples

You can use <a> or <button> for the nav links.

Link 1 Link 2 Link 3 Disabled 
<nav class="nav">
    <a href="#" class="nav-link">Link 1</a>
    <a href="#" class="nav-link">Link 2</a>
    <a href="#" class="nav-link">Link 3</a>
    <a href="#" class="nav-link disabled" aria-disabled="true" tabindex="-1">Disabled</a>
    <button class="nav-link">Button</button>
</nav>

This example uses <nav> for the sake of simplicity. You can use <ui> (or even <ol> for ordered items).

  • Link 1
  • Link 2
  • Link 3
  • Disabled 
<ul class="nav">
    <li class="nav-item><a href="#" class="nav-link">Link 1</a></li>
    <li class="nav-item><a href="#" class="nav-link">Link 2</a></li>
    <li class="nav-item><a href="#" class="nav-link">Link 3</a></li>
    <li class="nav-item><a href="#" class="nav-link disabled" aria-disabled="true" tabindex="-1">Disabled</a></li>
    <li class="nav-item><button class="nav-link">Button</button></li>
</ul>

You can make the link active by using .active followed by aria-current="true" (the latter is required for accessibility).

Link 1 Link 2 Link 3 Disabled 
<nav class="nav">
    <a href="#" class="nav-link active" aria-current="true">Link 1</a>
    <a href="#" class="nav-link">Link 2</a>
    <a href="#" class="nav-link">Link 3</a>
    <a href="#" class="nav-link disabled" aria-disabled="true" tabindex="-1">Disabled</a>
    <button class="nav-link">Button</button>
</nav>

Styles

You can style the nav by using additional classes to the nav element.

Vertical

You can make the navigation vertical by adding .flex-col class to the navigation. If needed, add .align-items-center to align the nav items.

Link 1 Link 2 Link 3 Disabled 
<nav class="nav flex-col align-items-start">
    <a href="#" class="nav-link active" aria-current="true">Link 1</a>
    <a href="#" class="nav-link">Link 2</a>
    <a href="#" class="nav-link">Link 3</a>
    <a href="#" class="nav-link disabled" aria-disabled="true" tabindex="-1">Disabled</a>
    <button class="nav-link">Button</button>
</nav>

Tabs

Add .nav-tabs to the nav container to turn into tabs.

Link 1 Link 2 Link 3 Disabled 
<nav class="nav nav-tabs">
    <a href="#" class="nav-link active" aria-current="true">Link 1</a>
    <a href="#" class="nav-link">Link 2</a>
    <a href="#" class="nav-link">Link 3</a>
    <a href="#" class="nav-link disabled" aria-disabled="true" tabindex="-1">Disabled</a>
    <button class="nav-link">Button</button>
</nav>

Or add .nav-tabs-framed to the nav container to frame the tabs in a background.

Link 1 Link 2 Link 3 Disabled 
<nav class="nav nav-tabs-framed">
    <a href="#" class="nav-link active" aria-current="true">Link 1</a>
    <a href="#" class="nav-link">Link 2</a>
    <a href="#" class="nav-link">Link 3</a>
    <a href="#" class="nav-link disabled" aria-disabled="true" tabindex="-1">Disabled</a>
    <button class="nav-link">Button</button>
</nav>

Overflow

Note: This feature requires JavaScript as it relies on js/nav.js, which is imported into the main JavaScript file, js/codexify.js.

When the nav is overflown, arrow buttons are added to the nav, one at start and one at end. Resize the container to see the effect.

Link 1 Link 2 Link 3 Link 4 Link 5 Disabled 
<div class="nav-overflow">
    <nav class="nav">
        <a href="#" class="nav-link active" aria-current="true">Link 1</a>
        <a href="#" class="nav-link">Link 2</a>
        <a href="#" class="nav-link">Link 3</a>
        <a href="#" class="nav-link">Link 4</a>
        <a href="#" class="nav-link">Link 5</a>
        <a href="#" class="nav-link disabled" aria-disabled="true" tabindex="-1">Disabled</a>
        <button class="nav-link">Button</button>
    </nav>
</div>
