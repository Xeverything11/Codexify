Popover

Small overlays to display custom information, via JavaScript.

Note: This component requires JavaScript as it relies on js/popover.js, which is imported into the main JavaScript file, js/codexify.js.

Examples

When the element triggering a popover is clicked, the popover is shown. Clicking that again hides it.

<button class="btn" data-c-toggle="popover" data-c-title="Popover" data-c-content="This is a popover">Default popover</button>

Placement

By default, popovers are placed to the right of the element. Popovers can be placed above, below, at left and right of the element.

<button class="btn" data-c-toggle="popover" data-c-placement="left" data-c-content="Left">Left</button>
<button class="btn" data-c-toggle="popover" data-c-placement="top" data-c-content="Top">Top</button>
<button class="btn" data-c-toggle="popover" data-c-placement="bottom" data-c-content="Bottom">Bottom</button>
<button class="btn" data-c-toggle="popover" data-c-placement="right" data-c-content="Right">Right</button>
