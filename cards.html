Cards

Display information in the customizable container.

Examples

Cards have no fixed width; you can pop them in grid slots.

Himalayas

Mountain range containing 100+ peaks 7,200 m+ above sea level.

Learn more 
<section class="card">
    <img src="...">
    <div class="card-body">
        <h3 class="card-title">...</h3>
        <p class="card-text">...</p>
    </div>
</section>

Card body

By default, cards have no padding, however you can add .card-body element inside .card to provide some padding around the card.

This is a card body container. You can use it to add title, content and buttons.

<section class="card">
    <div class="card-body">
        ...
    </div>
</section>

Or you can even add .card-body class into the .card class in an element.

This is a card body container. You can use it to add title, content and buttons.

<section class="card card-body">
     ...
</section>
