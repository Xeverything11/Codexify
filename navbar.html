Navbar

Responsive navigation bars, usually at top of pages.

Examples

This is the structure of the navbar.

Brand name

<header class="navbar">
    <nav class="container">
        <a class="navbar-brand" href="index.html">Brand name</a>
        <div class="flex-fill">
            <dialog class="offcanvas offcanvas-phone" id="navbarExample1">
                <div class="offcanvas-header">
                    <h1 class="offcanvas-title">Brand name</h1>
                    <button class="btn btn-quiet btn-icon" data-c-dismiss="offcanvas" aria-label="Close"><i class="icon icon-close"></i></button>
                </div>
                <div class="offcanvas-body tablet-d-flex">
                    <ul class="nav navbar-nav flex-col align-items-start tablet-flex-row tablet-align-items-center">
                        <li class="nav-item"><a class="nav-link active" href="#" aria-current="page">Link 1</a></li>
                        <li class="nav-item"><a class="nav-link" href="#">Link 2</a></li>
                        <li class="nav-item"><a class="nav-link" href="#">Link 3</a></li>
                    </ul>
                    <div class="d-flex flex-fill gap-4">
                        <input type="search" class="form-control" placeholder="Search...">
                        <button type="button" class="btn btn-icon" aria-label="Search"><i class="icon icon-search"></i></button>
                    </div>
                </div>
            </dialog>
        </div>
        <button class="btn btn-icon btn-quiet tablet-d-none" data-c-toggle="offcanvas" data-c-target="#navbarExample1" aria-label="Open menu"><i class="icon icon-menu"></i></button>
    </nav>
</header>

How it works?

A navbar combines a site header, a brand link, and navigation or other controls. The .navbar class provides the header background; its inner .container is a centered flex row with a 4rem height. The brand stays at its natural width, while .flex-fill lets the menu area take up the remaining space. The navbar is in normal document flow; it does not become fixed or sticky by itself.

Responsive menu

The example uses a native <dialog> with .offcanvas.offcanvas-phone for the navigation on phones. The menu button's data-c-toggle="offcanvas" and data-c-target="#navbarExample1" connect it to that dialog. The shared offcanvas script opens it modally, sets its accessible dialog-control attributes, locks page scrolling while it is open, and supports dismissal with the close button or Escape.

At the tablet breakpoint (640px), .offcanvas-phone changes the dialog to display: contents, so its contents participate in the navbar layout instead of appearing as a modal panel. The menu button is hidden by .tablet-d-none; .tablet-d-flex shows the menu's flex layout, and .tablet-flex-row changes the links from a vertical stack to a horizontal row. The offcanvas header is hidden when the dialog is closed at this size.

You can specify a different class to the navbar so the navbar collapses at different breakpoints

Collapse at phones

This variation keeps the menu collapsed below the tablet breakpoint (640px), then displays the navigation inline at wider sizes.

Navigation and controls

  • .nav, .nav-item, and .nav-link provide the shared navigation list and link styling. Use real anchors with destination URLs so the links work with the keyboard and browser navigation.
  • Mark the current destination with .active and aria-current="page"; the active class supplies the visual emphasis, while the ARIA attribute identifies the current page to assistive technology.
  • The search input and icon button are ordinary form controls. The example does not attach search behavior to them, so connect them to a form submission or your search logic when using them in an application.

Keep the menu toggle's accessible name (for example, aria-label="Open menu") and give each dialog a unique id that matches its toggle's data-c-target.

Positioning

By default, navbars are static, but you can make it fixed or sticky. You can even make it a frosted glass effect.
