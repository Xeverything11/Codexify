Reboot

Codexify normalises the code across every browsers, with opinioniated styles.

<body>

Margins and paddings are zeroed out in <body>.

body {
    margin: 0;
    padding: 0;
}

Headings

Headings, <h1> to <h6>, are styled with no top margins for <h1>, as well as generous top margins for other headings. They also have bottom margins for every heading, as well as tightened line heights. <h6> also have lighter font weight compared to other headings, as <h5> have 1rem font size (same as body text).

Paragraphs

All paragraphs have the top margin removed and bottom margin set to 1em for clear separation.
