Position

Adjust the positioning of an element.

Class Styles
.position-static position: static;
.position-relative position: relative;
.position-absolute position: absolute;
.position-fixed position: fixed;
.position-sticky position: sticky;

Example

Static

When an element is set to .position-static, it follows the normal flow. Insets and z-index are ignored.

Relative

When an element is set to .position-relative, it follows the normal flow and offset relative to itself using the inset utility classes. It creates a new stacking context when .z-index is anything but auto.

Absolute

When an element is set to .position-absolute, it positions to the positioned element, offseting it using the inset utility classes. It creates a new stacking context when .z-index is anything but auto.

Fixed

When an element is set to .position-fixed, it positions to the viewport, offseting it using the inset utility classes. It always creates a new stacking context.

You can see this element at bottom-right of the window.

See me? It's a fixed element.

<div class="position-fixed">...</div>

Sticky

When an element is set to .position-sticky, it treats as a relatively positioned element until scrolled enough, then it is absolutely positioned, offseting it using the inset utility classes. It always creates a new stacking context.

Note: At least one inset utility class (eg. .top-0) is required in order for an element to become stickily positioned.

Responsiveness

The position utilities are responsive, so you can change classes at different viewports, such as .position-static .tablet-position-relative .desktop-position-absolute .desktop-wide-position-static.
