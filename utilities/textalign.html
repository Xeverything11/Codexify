Text align

Control the alignment of the text.

Class Styles
.text-start text-align: start;
.text-center text-align: center;
.text-end text-align: end;
.text-justify text-align: justify;

Responsiveness

The text align utilities are responsive, so you can change classes at different viewports, such as .text-justify .tablet-text-start .desktop-text-center .desktop-wide-text-end.

This is justified text, which changes to start-aligned in tablets, center-aligned in desktops and end-aligned in wide desktops.

<p class="text-justify tablet-text-start desktop-text-center desktop-wide-text-end">...</p>
