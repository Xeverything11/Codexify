Z-index

Control the stack level of an element.

Class Styles
.z-bottom z-index: -100;
.z-base z-index: 0;
.z-toolbar z-index: 2;
.z-dropdown z-index: 50;
.z-sticky z-index: 100;
.z-fixed z-index: 200;
.z-offcanvas z-index: 350;
.z-overlay z-index: 450;
.z-popover z-index: 700;
.z-tooltip z-index: 800;
.z-toast z-index: 900;
.z-top z-index: 9999;

Approach

The following z-index values for components are shown here:

Component Class z-index
Toolbar .z-toolbar 2
Menus .z-dropdown 50
Sticky elements .z-sticky 100
Fixed elements .z-fixed 200
Drawer .z-offcanvas 350
Dialogs .z-overlay 450
Popovers .z-popover 700
Tooltips .z-tooltip 800
Toasts .z-toast 900
