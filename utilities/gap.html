Gap

Adjust the gap between child elements in a flexbox or grid parent element.

Class Styles
.gap-0 gap: 0;
.gap-1 gap: 0.125rem;
.gap-2 gap: 0.25rem;
.gap-3 gap: 0.375rem;
.gap-4 gap: 0.5rem;
