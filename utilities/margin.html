Example

You can combine multiple margin utilities, such as .mx-4 my-9 or .mt-4 mb-6 ms-8 me-9, to create complex layouts.

Align the block element to the center of the parent by using .mx-auto, start of parent using .me-auto, and end of parent using .ms-auto.
