Relative values

The classes .w-m-n are relative widths, where m is the numerator and n is the denominator. For example, .w-2-3 sets the width to ⅔ of parent element's width.

Minimum and maximum widths

You can add .min-w-* and .max-w-* classes to clamp the widths. Resize the container to see the effect.

This container is sized to w-1-2 (½ of parent element's width) but clamped to min-w-16 and max-w-22.
