Display

Adjust the layout of an element.

Class Styles
.d-block display: block;
.d-contents display: contents;
.d-flex display: flex;
.d-flow-root display: flow-root;
.d-grid display: grid;
.d-inline display: inline;
.d-inline-block display: inline-block;
.d-inline-flex display: inline-flex;
.d-inline-grid display: inline-grid;
.d-none display: none;

Contents

Applying display: contents to a parent element doesn't produce a box model themselves. They only render child and pseudo elements in the parent element.

Note: Child elements in the parent contents element are highlighted, for the sake of this document.

For example:

<div>1</div>
<div>2</div>
<div class="d-contents">
    <div>3</div>
    <div>4</div>
</div>

is equivalent to

<div>1</div>
<div>2</div>
<div>3</div>
<div>4</div>

Responsiveness

Display utilities are responsive, so you can set different layouts or even hide them at different viewports, such as .d-flex .tablet-d-grid .desktop-d-contents .desktop-wide-d-block.
