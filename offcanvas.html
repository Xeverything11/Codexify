Offcanvas

Hidden sidebars using native <dialog> elements that can be shown.

Note: This component requires JavaScript as it relies on js/offcanvas.js, which is imported into the main JavaScript file, js/codexify.js.

Examples

When the element triggering an offcanvas is clicked, the offcanvas is shown. Clicking the close button hides it.

Offcanvas title

This is an offcanvas.

 
<button class="btn" data-c-toggle="offcanvas" data-c-target="#exampleOffcanvas1">Default dialog</button>
<dialog class="offcanvas" id="exampleOffcanvas1">
    <div class="offcanvas-header">
        <h1 class="offcanvas-title">Offcanvas title</h1>
        <button class="btn btn-quiet btn-icon" data-c-dismiss="offcanvas" aria-label="Close"><i class="icon icon-close"></i></button>
    </div>
    <div class="offcanvas-body">
        <p>This is an offcanvas.</p>
    </div>
</dialog>
Caveat: The backdrop in offcanvas doesn't animate vis CSS (because that animation isn't supported in Firefox 115), instead the animation is implemented via JS.

You can add any components to the offcanvas, including tooltips and popovers.

Offcanvas title

 
<button class="btn" data-c-toggle="offcanvas" data-c-target="#exampleOffcanvas2">Offcanvas with components</button>
<dialog class="offcanvas" id="exampleOffcanvas2">
    <div class="offcanvas-header">
        <h1 class="offcanvas-title">Offcanvas title</h1>
        <button class="btn btn-quiet btn-icon" data-c-dismiss="offcanvas" aria-label="Close"><i class="icon icon-close"></i></button>
    </div>
    <div class="offcanvas-body">
        <div class="form-field">
            <label for="email" class="form-label">Email address</label>
            <input type="email" class="form-control" id="email" />
        </div>
        <div class="form-field">
            <label for="password" class="form-label">Password</label>
            <input type="password" class="form-control" id="password" />
        </div>
        <div class="form-field form-field-inline">
        <input type="checkbox" id="check" class="check" checked />
            <label for="check">Checkbox</label>
        </div>
        <div class="form-field form-field-inline">
        <input type="radio" id="radio1" name="radio" class="radio" checked />
            <label for="radio1">Radio 1</label>
        </div>
        <div class="form-field form-field-inline">
        <input type="radio" id="radio2" name="radio" class="radio" />
            <label for="radio2">Radio 2</label>
        </div>
        <div class="form-field form-field-inline">
        <input type="checkbox" id="switch" class="switch" checked />
            <label for="switch">Switch</label>
        </div>
        <button class="btn" data-c-toggle="tooltip" data-c-title="This is a tooltip">Tooltip</button>
        <button class="btn" data-c-toggle="popover" data-c-title="Popover" data-c-content="This is a popover">Popover</button>
    </div>
</dialog>

Responsive

Adding responsive classes hide the contents within the offcanvas from the normal viewport below the specific breakpoint and show as normal above that. Resize the window smaller to make more toggles appear.
