Layout

Codexify defines the layout using containers and breakpoints.

Breakpoints

Codexify provides 4 breakpoints: phones, tablets, desktops and wide desktops.

Breakpoint Class Min width Max width
Phones Not applicable 320px 640px
Tablets .tablet-* 640px 1120px
Desktops .desktop-* 1120px 1680px
Wide desktops .desktop-wide-* 1680px ∞

Right now, responsive utility classes are limited to display, grid-related ones, flexbox-related ones, inset, display, text align and font size. More will be added soon.

Containers

Containers are the most basic layout element in Codexify and works using the grid system by using .row. Containers have padding of 2rem to the left and right, which shrinks to 1rem on phones.

In addition to basic .container, which is full width until 1120px, there are .container-wide, which is full width until 1680px, and .container-fluid, which is always full width.

The grid system

Codexify features a grid system using the .row class. By default, it has 12 columns with gutter of 1rem between each other.

Nesting

.row elements can be nested inside each cell in another .row element. Simply add that class to the existing cell.

Level 1: col-4
Level 2: col-6
Level 2: col-6
<div class="container">
    <div class="row">
        <div class="col-4 ...">Level 1: col-4</div>
        <div class="col-8 row ...">
            <div class="col-6 ...">Level 2: col-6</div>
            <div class="col-6 ...">Level 2: col-6</div>
        </div>
    </div>
</div>

You can make the nested rows a subgrid using the .grid-cols-subgrid, so the nested row allocates the same number of rows as the cell. For example, a nested row in a cell spanning 8 columns has 8 columns.

Level 1: col-4
Level 2: col-4
Level 2: col-4
<div class="container">
    <div class="row">
        <div class="col-4 ...">Level 1: col-4</div>
        <div class="col-8 row ...">
                <div class="col-4 ...">Level 2: col-4</div>
                <div class="col-4 ...">Level 2: col-4</div>
            </div>
        </div>
    </div>
</div>

Positioning

You can position the columns by using .col-start-* and .col-end-* classes. This ranges from 1 to number of columns in a row plus 1.

Cell spanning from 3 to 7
Cell spanning from 6 to 11
Cell spanning from 1 to 5
Cell spanning from 7 to 13
<div class="container">
    <div class="row">
        <div class="col-start-3 col-end-7 ...">Cell spanning from 3 to 7</div>
        <div class="col-start-6 col-end-11 ...">Cell spanning from 6 to 11</div>
        <div class="col-start-1 col-end-5 ...">Cell spanning from 1 to 5</div>
        <div class="col-start-7 col-end-13 ...">Cell spanning from 7 to 13</div>
    </div>
</div>

Gutters

Rows have a gutter of 1rem between every cell by default, but you can adjust the gutter by using .gap-* (.gap-x-* for horizontal and .gap-y-* for vertical).

col-9 (row gutter set to 0.5rem / gap-2)
col-3
<div class="container">
    <div class="row gap-2">
        <div class="col-9 ...">col-9</div>
        <div class="col-3 ...">col-3</div>
    </div>
</div>
