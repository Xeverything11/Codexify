Dialog

Native <dialog> elements used as a modern component.

Note: This component requires JavaScript as it relies on js/dialog.js, which is imported into the main JavaScript file, js/codexify.js.

Examples

When the element triggering a dialog is clicked, the dialog is shown. Clicking the close button hides it.

Dialog title

This is a dialog.

 
<button class="btn" data-c-toggle="dialog" data-c-target="#exampleDialog1">Default dialog</button>
<dialog class="dialog" id="exampleDialog1">
    <div class="dialog-header">
        <button class="btn" data-c-dismiss="dialog">Close</button>
        <h1 class="dialog-title">Dialog title</h1>
        <button class="btn btn-primary btn-progressive">Next</button>
    </div>
    <div class="dialog-body">
        <p>This is a dialog.</p>
    </div>
</dialog>

You can add any components to the modal, including tooltips and popovers.

Dialog title

 
<button class="btn" data-c-toggle="dialog" data-c-target="#exampleDialog2">Dialog with components</button>
<dialog class="dialog" id="exampleDialog2">
    <div class="dialog-header">
        <button class="btn" data-c-dismiss="dialog">Close</button>
        <h1 class="dialog-title">Dialog title</h1>
        <button class="btn btn-primary btn-progressive">Next</button>
    </div>
    <div class="dialog-body">
        <div class="form-field">
            <label for="email" class="form-label">Email address</label>
            <input type="email" class="form-control" id="email" />
        </div>
        <div class="form-field">
            <label for="password" class="form-label">Password</label>
            <input type="password" class="form-control" id="password" />
        </div>
        <div class="form-field form-field-inline">
            <input type="checkbox" id="check" class="check" checked />
            <label for="check">Checkbox</label>
        </div>
        <div class="form-field form-field-inline">
            <input type="radio" id="radio1" name="radio" class="radio" checked />
            <label for="radio1">Radio 1</label>
        </div>
        <div class="form-field form-field-inline">
            <input type="radio" id="radio2" name="radio" class="radio" />
            <label for="radio2">Radio 2</label>
        </div>
        <div class="form-field form-field-inline">
            <input type="checkbox" id="switch" class="switch" checked />
            <label for="switch">Switch</label>
        </div>
        <button class="btn" data-c-toggle="tooltip" data-c-title="This is a tooltip">Tooltip</button>
        <button class="btn" data-c-toggle="popover" data-c-title="Popover" data-c-content="This is a popover">Popover</button>
    </div>
</dialog>
