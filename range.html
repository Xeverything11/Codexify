Range

Use the custom ranges with filled tracks.

Note: This form control requires JavaScript to style the filled track as it relies on js/range.js, which is imported into the main JavaScript file, js/codexify.js.

Overview

The <input type="range" /> element is hard to style using CSS. The filled track is inconsistent across browsers, only Firefox offers ::-moz-range-progress, so ranges use JavaScript to render the filled tracks.

To use it, simply add .form-range class to <input type="range" />.

<input type="range" id="range1" class="form-range" />

Disabled

Adding disabled attribute to <input type="range" /> grays out the range, as well as preventing from interacting.

<input type="range" id="range1" class="form-range" disabled />

Min and max values

By default, ranges have a minimum value of 0 and maximum value of 100. You can customize the minimum and maximum values.

<input type="range" id="range3" class="form-range" min="-5" max="5" />

Step values

By default, ranges snap to integer values. You can customize the step values.

<input type="range" id="range4" class="form-range" step="5" />

Form field

You can wrap the range in <div class="form-field"> to pair with a label.

<div class="form-field">
    <label for="range5" class="form-label">Volume</label>
    <input type="range" id="range5" class="form-range" />
</div>
